选卡对比

每张卡保留一个固定颜色，选中或取消不会让其它卡换色。第一条选中的是基线， 下面表格里的「为…的 N×」都以它为准。

指标

每个指标一张图，各自独立的刻度——不同单位不共用一个 y 轴。条形长度是线性比例： 短一半就是慢一倍。

数值表

图上标不下的数字都在这里，也是色弱或打印时的替代读法。

    这些数字在比什么
    

      只有所有卡都能产出的指标才进对比图。GEMV 的绝对时间依赖层形状和 Windows 的提交地板，
      跨卡排序基本等于排驱动版本，所以它只出现在每条记录的详情里，不参与排名。


      解码按 3 B/元素计有效带宽（读 1 B、写 2 B）；拷贝带宽按双程计。所有数值都是
      interleaved/looped CUDA event 的中位数——这张卡是共享的，单次计时会摆动 2–4×。


      重要：本机实测的是同一张 2080 Ti 上不同时刻的状态，跨卡对比需要你在那台机器上
      跑一遍再导入。没有别的显卡的真实数据时，这张页面比较的是「同一张卡在两个时间点」。
